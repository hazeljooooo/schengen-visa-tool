# 申根签证申请表填写工具

离线填写申根签证申请信息，并导出已填入内容的官方 PDF 申请表。

## 当前支持导出

| 国家 | 领区 / 表单 | 状态 |
| --- | --- | --- |
| 西班牙 | 统一申请表 | 可导出 PDF |
| 意大利 | 北京、上海、广州、重庆领区 | 可导出 PDF |
| 希腊 | 驻华使馆申请表 | 可导出 PDF |
| 瑞典 | 统一申请表 | 可导出 PDF |
| 冰岛 | 统一申请表 | 可导出 PDF |
| 奥地利 | 驻华使馆申请表 | 可导出 PDF |
| 匈牙利 | 驻华使馆申请表 | 可导出 PDF |

法国、德国、挪威、芬兰、丹麦、荷兰、比利时和瑞士目前仅提供官网申请入口，尚不支持 PDF 导出。

领区划分和申请表版本可能会随使领馆规则调整。提交申请前，请确认自己所属领区，并以对应使领馆发布的最新要求为准。
